# Podcast: A semelhança entre as redes neurais e o cérebro 🎙️

## 📒 Descrição
Um curto áudio demonstrando a semelhança entre as redes neurais e o cérebro humano, desenvolvido inteiramente em IA.

## 🤖 Tecnologias Utilizadas
- IA Generativa **[ChatGPT](https://chat.openai.com)** para roteirização e revisão;
- IA Generativa **[ElevenLabs](https://www.elevenlabs.io)** para clonagem e sintetização de voz;

## 🧐 Processo de Criação
O ChatGPT foi usado para desenvolver o texto e o ElevenLabs para transformar o texto em narração virtual.

## 🚀 Resultados
Um áudio de um minuto e meio explorando as similaridades entre as estruturas humanas e sintéticas da inteligência.
